How to collect a useful sample

Start the same map with Autoplay. Use native resolution and vsync. These controls move focus away from the game, so use Autoplay to avoid pausing. Enable show FPS in settings, then read timings before opening CPU stats.

CPU stats opens lazer's existing Ctrl+F2 window. Move the pointer inside that window and scroll down to Update (Top CPU consumers). Capture those five rows, then scroll to the Draw and Update counters for another capture.

This profiler adds CPU work and drawables. Its ranking identifies costly types; its FPS is not a normal-play benchmark. Close CPU stats after collecting the samples. Cycle frame graph sends Ctrl+F11; click again to cycle back off.

The game keeps the full browser viewport. Captures stay on this device. This page uses the existing build and does not change gameplay code or saved settings.
